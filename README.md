

# [MindMirror] AI 일기 자동화 시스템 최종 보고서

## 1. 자동화할 반복 업무 정의
**"일기 작성 리마인드 - AI 분석 및 시각화 - 미작성자 사후 케어"**
단순히 일기를 저장하는 것을 넘어, 정해진 시간에 작성을 유도하고, 작성된 내용을 AI가 요약·이미지화하며, 기록을 놓친 날에는 운세로 마음을 달래주는 통합 감정 관리 프로세스를 자동화합니다.

## 2. 자동화 도구 선정
*   **구글 폼:** 일기 입력 인터페이스
*   **구글 스프레드시트:** 데이터 저장 및 관리 (DB)
*   **Gemini API:** 일기 요약 및 운세 메시지 생성
*   **Apps Script:** 전체 시스템의 트리거 및 로직 제어

---

## 3. 핵심 워크플로우 (Trigger-Filter-Action)

사용자님의 시스템은 총 3단계의 자동화 시나리오로 구성됩니다.

### ① 시나리오 A: 밤 10시 작성 알림 (리마인드)
| 구분 | 내용 | 상세 설명 |
|:---:|:---|:---|
| **TRIGGER** | **매일 밤 10시 (시간 기반)** | Apps Script의 시간 기반 트리거가 작동 |
| **ACTION** | **알림 메일 발송** | 구글 폼 링크가 담긴 메일을 사용자에게 발송하여 작성을 유도 |

### ② 시나리오 B: 일기 작성 및 AI 분석 (실시간 처리)
| 구분 | 내용 | 상세 설명 |
|:---:|:---|:---|
| **TRIGGER** | **구글 폼 제출 (이벤트 기반)** | 사용자가 일기 작성을 마치고 '제출' 버튼을 누르는 순간 작동 |
| **ACTION 1** | **AI 한 줄 요약** | Gemini AI가 일기 내용을 분석하여 따뜻한 요약문 생성 |
| **ACTION 2** | **AI 이미지 생성/연결** | 일기 분위기에 맞는 이미지를 생성하거나 매칭하여 시트에 저장 |
| **ACTION 3** | **시트 데이터 업데이트** | 요약과 이미지 정보를 '나의 일기장' 시트 G열 등에 자동 기록 |

### ③ 시나리오 C: 미작성자 사후 케어 (익일 아침)
| 구분 | 내용 | 상세 설명 |
|:---:|:---|:---|
| **TRIGGER** | **다음 날 오전 9시 (시간 기반)** | 어제 일기 작성 여부를 확인하기 위해 트리거 작동 |
| **FILTER** | **어제 날짜 기록 확인** | **[조건]** 스프레드시트에 어제 날짜의 데이터가 있는가? |
| **ACTION** | **AI 운세 메일 발송** | **[결과]** 데이터가 없다면(미작성), AI가 생성한 위로의 운세 메일 발송 |

## 4. 데이터 흐름 다이어그램

```
[PM 10:00] ⏰ 트리거: "일기 쓸 시간이에요!"
      └─> ACTION: 리마인드 메일 발송 📧

[사용자] ✍️ 구글 폼에 오늘 하루 기록 및 제출
      └─> TRIGGER: 양식 제출 이벤트 발생

[AI 처리] 🧠 Gemini AI 가동
      ├─> ACTION 1: 일기 내용 따뜻하게 요약
      └─> ACTION 2: 일기 분위기 시각화(이미지) 및 시트 저장 📊

[AM 09:00] ⏰ 트리거: "어제 일기 썼나?"
      └─> FILTER: 시트 데이터 검사
            ├─ [작성 완료] -> 종료 (평온한 아침)
            └─ [미작성] -> ACTION: AI 위로 운세 발송 🍀
```

---

## 5. 구현 코드의 핵심 로직 (Apps Script)

*   **트리거 설정:** `sendReminderEmail`(밤 10시), `onFormSubmit`(폼 제출 시), `checkDiaryAndSendFortune`(아침 9시) 3가지 트리거를 통해 시스템이 멈추지 않고 순환합니다.
*   **필터링 기술:** `checkDiaryAndSendFortune` 함수 내에서 `for`문과 `if`문을 사용하여 어제 날짜의 데이터 존재 여부를 정확히 판별합니다.
*   **AI 통합:** `getAiSummary` 함수 하나로 요약과 운세 생성을 모두 처리하여 코드의 효율성을 높였습니다.

---

## 6. 기대 효과
1.  **강제성 없는 습관 형성:** 밤 10시 알림이 규칙적인 기록 습관을 만들어줍니다.
2.  **자기 객관화:** AI의 요약과 이미지를 통해 내 감정을 제3자의 시선으로 바라볼 수 있습니다.
3.  **심리적 안전망:** 일기를 쓰지 못한 날에도 비난 대신 AI의 다정한 운세를 받음으로써 긍정적인 마음가짐을 유지할 수 있습니다.
