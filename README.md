# 📋 [프로젝트 2] 자유 주제 자동화 설계 및 구현

## 1. 자동화할 반복 업무 정의

> **매일 반복되는 "일기 감정 케어" 업무**

매일 일기를 쓰고 나서, 스스로를 위로하고 격려하는 말을 떠올리는 일은 번거롭고 반복적입니다. 이 과정을 AI가 자동으로 처리하여, 일기를 쓰면 **즉시 따뜻한 위로 답장**을 받을 수 있도록 자동화합니다.

---

## 2. 자동화 도구 선정 및 이유

| 선정 도구 | 구글 스프레드시트 + Gemini(AI 함수) |
|-----------|-------------------------------------|
| **선정 이유** | ① **구글 계정 하나**로 시트·AI·메일을 모두 통합 관리 가능 → 계정 관리가 편리<br>② **코딩 없이** 함수 한 줄로 AI를 사용할 수 있어 진입장벽이 낮음<br>③ 별도 설치·비용 없이 웹에서 바로 실행 가능 |

---

## 3. 워크플로우 설계 문서

### 🔄 전체 흐름 (입력 → 처리 → 출력)

```
[Trigger]                [Filter]              [Action 1]           [Action 2]
일기 입력      →     내용이 있는가?    →   Gemini AI 호출   →   답장 자동 표시
(B열 작성)          (빈칸 걸러내기)        (위로 문구 생성)      (C열에 출력)
                          │
                          └─ 빈칸이면 → 아무 동작 안 함 (대기)
```

### 📌 구성 요소 상세 설명

#### ① Trigger (트리거 - 자동화 시작 조건)
- **B열(일기 칸)에 사용자가 일기를 입력하고 Enter를 누르는 순간** 자동화가 시작됩니다.
- 사람이 일기를 쓰는 행동이 곧 "시작 버튼" 역할을 합니다.

#### ② Filter (조건 분기 - 걸러내기)
- **일기 칸(B열)이 비어 있는지 검사**합니다.
- **내용이 있으면** → AI 처리로 진행 ✅
- **비어 있으면** → 답장을 만들지 않고 대기 (불필요한 AI 호출 방지) ⏸️

#### ③ Action 1 (동작 1 - AI 호출)
- Gemini AI에게 일기 내용을 전달하여 **위로·격려 문구를 생성**합니다.

#### ④ Action 2 (동작 2 - 결과 출력)
- 생성된 답장을 **C열(토순이의 답장 칸)에 자동으로 표시**합니다.

---

### 💻 실제 구현 함수 (조건분기 포함)

```
=IF(B2="", "", AI("너는 따뜻하고 다정한 상담 토끼 '토순이'야.
반말로 친근하게 위로하고 격려해줘. 아래 일기를 읽고 답장해줘: " & B2))
```

> **함수 해설**
> - `IF(B2="", "", ...)` → **[Filter]** 일기가 비어 있으면 아무것도 안 하고, 내용이 있을 때만 실행
> - `AI(...)` → **[Action 1]** Gemini가 위로 문구 생성
> - 결과가 C열에 표시됨 → **[Action 2]** 답장 자동 출력

## 4. 구성 요소 요약표 (제출 체크용) ✅

| 요구 조건 | 우리 프로젝트에서의 구현 | 개수 |
|-----------|--------------------------|------|
| **Trigger** | 일기 입력(B열 작성) | 1개 ✅ |

| **조건 분기(Filter)** | 일기 빈칸 여부 검사(IF 함수) | 1개 ✅ |
