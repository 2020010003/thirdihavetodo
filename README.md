## 1. 자동화할 반복 업무 정의
매일 반복되는 "일기 감정 케어" 업무

매일 일기를 쓰고 나서, 스스로를 위로하고 격려하는 말을 떠올리는 일은 번거롭고 반복적입니다. 이 과정을 AI가 자동으로 처리하여, 일기를 쓰면 즉시 따뜻한 위로 답장을 받을 수 있도록 자동화합니다.

## 2. 자동화 도구 선정 및 이유

**선정 도구: 구글 스프레드시트 + Gemini(AI 함수)**

### ✅ 선정 이유 5가지

| 번호 | 기준 | 상세 설명 |
|------|------|-----------|
| **①** | **계정 통합 관리** | 구글 계정 **하나**로 스프레드시트·Gemini·Gmail을 모두 사용 가능. 여러 서비스에 가입할 필요가 없어 아이디·비밀번호 관리 부담이 없음 |
| **②** | **낮은 코딩 난이도** | 프로그래밍 언어 없이 **함수 한 줄**로 AI를 호출. 초보자도 복사·붙여넣기로 바로 구현 가능 |
| **③** | **비용 부담 없음** | 별도 유료 구독이나 프로그램 설치 없이 **무료**로 웹에서 바로 사용 |
| **④** | **빠른 실행 속도** | 일기를 입력하면 **몇 초 안에** 결과가 표시되어 즉각적인 피드백을 받을 수 있음 |
| **⑤** | **접근성·호환성** | PC·태블릿·스마트폰 어디서든 브라우저만 있으면 접속 가능. 자동 저장되어 데이터 손실 걱정 없음 |

### 🔧 Google Apps Script를 활용한 Gmail 자동 발송 구현

#### 1. 개요
구글 시트에 작성된 일기와 AI(Gemini)가 생성한 답장을
**Google Apps Script**를 통해 **Gmail로 자동 발송**되도록 구현하였다.

---

#### 2. 구현 방법

**① Apps Script 접근**
구글 시트 상단 메뉴의 `확장 프로그램 → Apps Script`를 통해
코드 편집기(Code.gs)에 접근하였다.

**② 코드 구조 및 동작 원리**

| 단계 | 코드 | 역할 |
|------|------|------|
| 시트 연결 | `SpreadsheetApp.getActiveSheet()` | 현재 작업 중인 시트를 불러옴 |
| 데이터 추출 | `getRange("B2").getValue()` | 일기(B2)와 답장(C2) 값을 가져옴 |
| **필터** | `if (일기=="") return;` | 일기가 비어있으면 발송 중단 |
| **액션** | `generate("c2"),GmailApp.sendEmail()` | 구글 스프레드 c2값 생성 ,Gmail로 메일 자동 발송 |
| **트리거** | `getRange("B2")` | 일기(B2)에 사용자가 값을 입력 |

┌─────────────────────────────────────────────┐
│         [1] TRIGGER (트리거)                  │
│   실행 버튼 클릭 → 코드 실행 시작              │
│   SpreadsheetApp.getActiveSheet()            │
│   : 현재 구글 시트에 연결                      │
└─────────────────┬───────────────────────────┘
                  ⬇️
┌─────────────────────────────────────────────┐
│         [2] 데이터 추출                        │
│   getRange("B2").getValue() → 일기 가져오기   │
│   getRange("C2").getValue() → 답장 가져오기   │
└─────────────────┬───────────────────────────┘
                  ⬇️
┌─────────────────────────────────────────────┐
│         [3] FILTER (필터)                     │
│   if (일기 == "") return;                     │
│   : 일기가 비어있으면 메일 발송 중단           │
└─────────────────┬───────────────────────────┘
                  ⬇️
┌─────────────────────────────────────────────┐
│         [4] ACTION (액션)                     │
│   GmailApp.sendEmail(받는사람, 제목, 내용)    │
│   : 일기 + AI 답장을 Gmail로 자동 발송         │
└─────────────────┬───────────────────────────┘
                  ⬇️
┌─────────────────────────────────────────────┐
│         [5] 결과 확인                          │
│   Logger.log("메일 발송 완료!")               │
│   : 실행 로그로 정상 작동 확인                 │
└─────────────────────────────────────────────┘

**③ 메일 구성**
- 받는사람: 사용자 본인 이메일
- 제목: "🐰 토순이의 오늘 답장이 도착했어요!"
- 내용: 오늘의 일기 + 토순이의 답장

---

#### 3. 실행 결과
`실행 로그`를 통해 정상 작동을 확인하였다.
```
4:29:53  실행이 시작됨
4:29:54  메일 발송 완료!   ✅
4:29:55  실행이 완료됨
```
→ 코드 실행 후 **약 1초 만에 메일이 성공적으로 발송**되었으며,
Gmail 받은편지함에서 답장 메일 수신을 확인하였다.

---

#### 4. 두개의 툴 비교 
기존에는 시트에서 답장을 **직접 확인**해야 했으나,
Apps Script 연동을 통해 **일기 → AI 답장 → 메일 수신**까지의
전 과정이 **자동화**되어 사용자 편의성이 향상되었다.
